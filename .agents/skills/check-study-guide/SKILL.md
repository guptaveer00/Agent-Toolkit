# Check a statistics study guide

Review the draft in a fresh session. Read the guide and the saved MCP response supplied for it. Leave the draft and source files untouched.

1. Identify each factual claim in the explanations and recall answers.
2. Judge support using only the pages cited for that claim in the draft. If another retrieved page supplies missing evidence, list it separately as a citation gap. A search rank or a topical match is insufficient evidence.
3. For each supporting passage, identify its result ID and quote a short exact excerpt. If you derive a claim from the excerpt, label it as a derivation and give the reasoning. Use the original PDF page number from the MCP result.
4. Mark a claim SUPPORTED when the cited text supports it, PARTIAL when it supports only part of the claim, or UNSUPPORTED when support is missing or the passage contradicts it.

Use one line per claim:

`[STATUS] <claim or answer> | PDF page <number or missing> | <result ID and exact excerpt, with derivation if needed, or reason support is missing>`

End with the highest-priority gaps, if any. Report findings only.
